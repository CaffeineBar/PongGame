## About This Project
This project is a personal practice project aimed at learning the fundamentals of **GDScript** programming and input logic systems using the **Godot Engine**. This game is specifically designed for a **local 2-player** head-to-head mode.

## Key Features
* **Local 2-Player Mode**: Player 1 uses keyboard keys (W/S) and Player 2 uses the Arrow keys (Up/Down) to move their paddles.
* **Automatic Scoring System**: Scores update in real-time whenever the ball passes an opponent's boundary line.
* **Dynamic Bouncing**: The ball's bounce angle changes depending on where it hits the paddle.
* **Simple UI**: Clean interface for score tracking and game over/restart notifications.

## Notes & Modifications
I originally learned the basics of this game from a YouTube tutorial, but I made several modifications and personal tweaks, including:
* Customizing the ball's movement speed and difficulty acceleration curves.
* Redesigning the score UI layout to make it cleaner and easier to read on screen.
* Adding basic sound effects or background audio adjustments (optional).
